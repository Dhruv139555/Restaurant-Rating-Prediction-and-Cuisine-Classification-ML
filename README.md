# 🍽️ Restaurant Rating Prediction & Cuisine Classification using Machine Learning

An end-to-end Machine Learning project that predicts restaurant ratings and classifies cuisines using real-world restaurant data. This project demonstrates complete ML workflow including data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation using industry-standard techniques.

Built using Python and Google Colab, this project showcases practical implementation of supervised machine learning for business intelligence and predictive analytics.

---

## 🚀 Project Objectives

This project focuses on solving two real-world business problems:

1. 🎯 Regression Task  
   Predict restaurant **Aggregate Rating** based on features like location, votes, cost, and services.

2. 🎯 Classification Task  
   Predict restaurant **Cuisine Category** using machine learning classification techniques.

These predictions can help businesses improve customer satisfaction, optimize services, and support decision-making.

---

## 📊 Dataset Information

- File: `Dataset.csv`
- Type: Structured Restaurant Dataset
- Contains features such as:
  - Restaurant Name
  - Location
  - Votes
  - Average Cost
  - Online Delivery
  - Table Booking
  - Cuisines
  - Aggregate Rating (Target for Regression)

---

## 🧠 Machine Learning Models Used

### 1️⃣ Regression Model
- Algorithm: Random Forest Regressor
- Target Variable: Aggregate Rating
- Purpose: Predict restaurant ratings
- Evaluation Metrics:
  - Mean Squared Error (MSE)
  - R² Score

### 2️⃣ Classification Model
- Algorithm: Random Forest Classifier
- Target Variable: Cuisines
- Purpose: Predict restaurant cuisine category
- Evaluation Metrics:
  - Accuracy Score
  - Classification Report
  - Confusion Matrix
